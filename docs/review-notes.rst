Sphinx guide. The implementation uses the supplied plan and locally available
repository snapshots; it does not establish that any untested upstream update
is ready to adopt.

Validation record
-----------------

Validation used Sphinx 6.2.1, sphinx-rtd-theme 1.2.2, and docutils 0.18.1.

* Strict HTML and LaTeX generation passed with ``-n -W --keep-going``.
* Five SVG figures and five PDF figures were generated by Sphinx/Graphviz.
  All HTML figure pages were inspected in a headless browser at 1280px width;
  none caused horizontal page overflow. Selected manual pages were also
  visually inspected, including release coordination and reference tables.
* All 15 generated HTML pages and 576 local references were checked, including
  linked assets and fragments. Every original page URL and explicit internal
  anchor was retained; useful former heading anchors have landing aliases.
* All 10 public links, including the review-comment anchor, responded
  successfully. The normal linkcheck encountered the local proxy's untrusted
  certificate chain on Read the Docs. A separate diagnostic linkcheck passed
  with TLS verification bypassed for that process only. No TLS override or
  ignored-link list was added to the repository; certificate-authenticated
  checking of those hosts remains an environment limitation.
* Spack's local version parser confirmed the documented open-ended and bounded
  range behavior for 2025.12.1, 2026.07, and ``develop``. No package
  concretization or installation was needed for that semantic check.
* The complete manual compiled with the installed Homebrew TeX distribution.
  The default PATH selected a separate, incomplete TeX installation. For this
  local verification, PATH selected Homebrew's binaries and TEXINPUTS exposed
  its existing package tree. No system TeX files were changed. A temporary
  package-download attempt was unnecessary once that installation was located.

Local outputs are ``docs/_build/html/index.html`` and
``docs/_build/latex/RADIUSS_Spack_Configs.pdf``; generated outputs are ignored
by Git. No LC builds, Spack package builds, or GitLab pipelines were executed.
